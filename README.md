# Django Workshop
Introduction to Django web application development by MJ Duarte Rosa.

#### Prerequisites:
- Prior experience of Python
- Technical English
- Web Development basics
- HTML + JS + CSS background

## Structure of the workshop:

### Topic 1: Introduction to Django (1 hour)
| Section | Topic |
|---|---|
| A | Overview of the Django framework |
| B | Installing and setting up Django |
| C | Creating a Django project and application |

### Topic 2: URL Routing and Views (2 hours)
| Section | Topic |
|---|---|
| A | Understanding URL routing in Django |
| B | Creating views to handle HTTP requests |
| C | Working with URL patterns and regular expressions |
| D | Using generic views for common tasks |

### Topic 3: Templates and Static Files (2 hours)
| Section | Topic |
|---|---|
| A | Overview of Django templates |
| B | Creating and using template files |
| C | Templating language and syntax |
| D | Serving static files (CSS, JavaScript, images, etc.) |

### Topic 4: Models and Databases (2 hours)
| Section | Topic |
|---|---|
| A | Introduction to Django's models and ORM |
| B | Defining models and fields |
| C | Using the Django shell for database interactions |
| D | Migrating and updating database schema |

### Topic 5: Forms and User Input (2 hours)
| Section | Topic |
|---|---|
| A | Working with Django forms |
| B | Validating user input |
| C | Rendering forms in templates |
| D | Customizing form behavior and appearance |

### Topic 6: Advanced Django Features (2 hours)
| Section | Topic |
|---|---|
| A | Django middleware and how it works |
| B | Customizing authentication and authorization |
| C | Working with Django signals and celery tasks |
| D | Using Django&#39;s caching framework |

### Topic 7: Deployment and Production (2 hours)
| Section | Topic |
|---|---|
| A | Overview of Django deployment options |
| B | Deploying Django to a production server |
| C | Configuring Django for production use |
| D | Best practices for deploying and maintaining a Django application |
